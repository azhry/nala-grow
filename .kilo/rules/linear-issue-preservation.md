# Linear issue rules

- Never overwrite the issue description. If the original description is incomplete, prepend or append the implementation contract while preserving all original reference material verbatim.
- Preserve user-supplied reference material (including HTML, screenshots, designs, and examples) verbatim. Add the implementation contract before or after the reference; do not overwrite, shorten, or paraphrase the reference unless the user explicitly asks.
- Load only the required credential without output, and never print, echo, commit, or transmit secret values.
